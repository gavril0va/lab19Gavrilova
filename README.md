## Тема

Строки в C#.

## Что реализовано

- определение длины строки;
- подсчёт букв, цифр, пробелов и слов;
- поиск первого индекса символа;
- удаление пробелов по краям;
- перевод в верхний регистр;
- замена пробелов на подчёркивания.

## Короткие ответы
1. string — это строка текста в двойных кавычках ("хэло ворлд"). а char — это один символ в одинарных ('П').
2. строки в C# неизменяемые. Trim() возвращает новую строку, а старая остается прежней.
3. чтобы не появлялись пустые слова, если между словами (или по краям) несколько пробелов.
